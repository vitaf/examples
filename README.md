# MindCopy Examples

Примеры сетей, плагинов и экспериментов для платформы MindCopy.

## Файлы

- `test_single_neuron.bion` — тестовый нейрон (сома + 2 дендрита + аксон + PRE/POST)
- `test_single_neuron.bexp` — тестовый эксперимент
- `experiments/` — 16 образовательных экспериментов (бакалавриат/магистратура/аспирантура)

## Эксперименты

См. [experiments/README.md](experiments/README.md)

## БИОЛОГИЧЕСКАЯ ДОСТОВЕРНОСТЬ

Все симуляции используют полный биологический тик Core (core_run_tick):
- Ионные каналы: полная кинетика Ходжкина-Хаксли/GHK
- Синапсы: реалистичная кинетика выброса/связывания/клиренса
- Пластичность: CaMKII/Calcineurin сигнальные пути
- Без суррогатов — все вычисления через физиологически обоснованные модификаторы
